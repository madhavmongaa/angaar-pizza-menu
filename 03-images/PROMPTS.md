# Gemini image prompts (16 images)

How to use:
1. Open Gemini, start one chat, and choose image generation.
2. Paste one prompt at a time. Each prompt already includes the style line.
3. Download the image at full size and save it in a new folder called `pizza-images` inside Downloads, with the exact file name shown above the prompt. PNG or JPG are both fine.
4. Check before saving: the pizza is seen from straight above, is whole and centred, and the background is plain white. If not, reply "same again, perfectly top-down, plain white background, nothing else in the frame".

The small Gemini mark in the corner is fine. It gets removed when the images are cut out.
